# Xj's Drinking Game

Welcome to a tiny chaos factory made of React, TypeScript, and questionable competitive energy.

This repo is a collection of lightweight party and drinking games for the browser. Right now it includes:

- Higher or Lower
- Mind Meld
- Splurt
- We're Not Really Strangers

The goal is simple:

- keep the games fast
- keep the UI playful
- keep the code clean enough that another human can jump in without crying

## Why Contribute?

Because this project is a fun place to:

- add weird little social games
- improve game feel and animations
- clean up UX for mobile party play
- practice shipping features without enterprise sludge

If you’ve ever thought:

> “I could absolutely make this sillier, cleaner, or more chaotic.”

...you are the exact type of menace this repo wants.

## Tech Stack

- React
- TypeScript
- Material UI
- Create React App

## Local Setup

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm start
```

Run tests:

```bash
npm test -- --watchAll=false
```

Build production bundle:

```bash
npm run build
```

## Deploy

Deploy the site with:

```bash
npm run deploy
```

## Contributing

Contributions are welcome, especially if you want to:

- add a new game
- improve UI clarity
- make mobile play better
- refactor messy spots into cleaner feature folders
- add better tests

Good contributions are:

- simple
- readable
- fun
- not wildly overengineered

If you open a PR with a better game flow, cleaner component structure, or a fun new idea, there is a very high chance it will be appreciated.
